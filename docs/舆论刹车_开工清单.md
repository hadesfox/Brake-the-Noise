# 《舆论刹车》 Brake the Noise — 开工清单

> 用途：开工前 1 小时的准备动作 + 7 天执行清单
> 状态标记：☐ 未开始 ／ ◐ 进行中 ／ ☑ 完成

---

## 第一步：先解决 3 件阻塞级的事（预计 30 分钟）

### ☐ 1. 目标平台

- [ ] 决定：PC / Web / 移动（三选一）
- [ ] 若 Web：确认 AI 平台的构建产物能不能直接跑
- [ ] 确认下载分发方式（玩家怎么拿到游戏）

**为什么最急**：影响输入方式（键盘/触屏）、分辨率、判定条尺寸。

---

### ☐ 2. AI 的调用点

- [ ] 列出所有"需要 AI 生成"的位置
- [ ] 划清边界：哪些必须 AI，哪些模板就够

**建议边界**

| 位置 | 用不用 AI | 理由 |
| --- | --- | --- |
| 帖子文案（曲解三档） | ✅ 用 | 需要批量、风格化 |
| 结局描述长文本 | ✅ 用 | 一次性、无精确要求 |
| 因果清算文案 | ❌ 模板 | 需要精确对应数据，不能乱 |
| 帖子定性逻辑 | ❌ 规则 | 必须可预测 |

---

### ☐ 3. Fallback 方案

- [ ] 准备纯模板版本（AI 不可用时自动降级）
- [ ] 测试：把 AI 关掉，游戏能不能跑完

**模板格式建议**

```
「{力值}N！这{部件}是{形容词}的！」—— {用户类型}
示例：「1480N！这踏板是纸糊的！」—— 路人甲

变量池：
  形容词 = [纸糊的, 离谱的, 脆得吓人, 有问题]
  用户类型 = [路人甲, 懂车帝, 老司机, 匿名用户, 吃瓜群众]
```

## 第二步：建项目 + 最小 Demo（预计 20 分钟）

- [ ] 建空项目，能运行
- [ ] 做一个最小 demo：**一个按键 + 一个来回扫的条 + 停下出数值**

## 第四步：文案模板格式定稿（预计 10 分钟）

- [ ] 确定帖子文案的模板语法
- [ ] 写 3 条样例（三档各一条）
- [ ] 确定变量占位符命名规范

**样例**

```
[轻微] 「{力值}N，我{动作}{结果}」→「1480N，我踩断了它！」
[中度] 「{力值}N！{部件}怕是{形容词}」→「1480N！踏板怕是纸糊的」
[重度] 「#{标签}# {诉求}」→「#我踩断了它# 要求召回」
```
