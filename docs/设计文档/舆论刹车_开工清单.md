## 7 天执行清单

### ◐ D1：两轮判定 + 新载荷模型

- [ ] 两轮判定（落点含接触 / 力度）；L取杆端支点与真实交集面积重心，A有效采用已确认的A集中×E传导。
- [ ] F=80～1612 N；疲劳减力并参与漂移，仅暴躁收窄。甜蜜区中心50%±18个百分点、全宽10%～4%，向两端连续渐变，按下即时采样。
- [ ] 游戏等效载荷`T=F×L×A有效×K姿势`；配置和档案契约移除旧八K强制连乘。
- [ ] 正式结算仅展示F及真实感觉/实际时间，不展示T或隐藏状态数字；感觉显示封顶4秒且保留原值，实际时间来自刹车模拟。

- **验收：两轮按新模型计算，记录可复现；不要求每次数字必不同。旧P1.1手感已确认，P1.2/P1.3新模型未验收。正式时间结算与演出在D2接齐。**

### ☐ D2：人体状态 + 温度 + 损伤 + 机会限制

- [ ] K最终仅姿势；k1/k2/k6/k8退出当前模型，k3疲劳/k5暴躁进入F形成过程，k7成为单一平滑温度。
- [ ] 天气/空调改变温度目标；温度分别影响人体状态累积与`M有效=M剩余×C温度`，不重复乘进K。
- [ ] 本轮载荷/有效余量判定后，将未断情况下的新增永久损伤记入下一轮；普通载荷损伤零或很小，近边界增加，无固定扣血、保底或额外断裂随机。
- [ ] 同局最多三次 + 决策点；断裂可换车继续，不重置总次数、人体状态或历史；踩空不计算载荷，机会消耗与流程待定。
- [ ] 刹车模拟、感觉/实际用时、0.5秒全静音与结算演出；视频缺失仍能以2D完成剧情。

- **验收：第三次后必须发帖，第一次后可提前发帖；换车不重置次数，本轮判定不提前扣次轮损伤；时间真实，无局内隐藏数字泄漏。**

### ☐ D3：发帖

- [ ] 词条解锁逻辑
- [ ] 拼句子 UI
- [ ] 发送时机（敏感度曲线）
- [ ] 帖子定性 → 曲解方向

- **验收：能发出一帖，且有方向属性**

### ☐ D4：因果清算 + 全流程闭环 ★ 硬里程碑

- [ ] 真实记录 → 精确清算文案，冷静视觉风格与逐条揭晓，保留确认/翻页互动。
- [ ] 接入最低限度原帖、模板洪流与多帖聚焦结局；玩家署名但不是原话，无系统总结和局内重开按钮。
- [ ] 局外测试档案可查询完整因素、历史、原帖与最终结果，处理空档案/读取失败。

- **验收：从测试到署名结局完整跑通，清算对应真实记录，完成后档案可查；仅清算序列不能算D4完成。**

### ☐ D5：B 段（信息流洪流）

- [ ] 原帖保留不可变副本；来源关系可追溯。
- [ ] 信息流滚动 + 帖子逐条冒出，玩家可刷新/点击来源，不做独立传播树或传播数字栏。
- [ ] 曲解三档 × 三方向逻辑，结果对应真实选择。
- [ ] 嘈杂视觉风格。
- [ ] 多帖聚焦至玩家署名帖，优先“崇高化”，最终安静定格。

- **验收：能看到完整洪流 + 结局落点**

### ☐ D6：美术 + 音效 + 内容

- [ ] 2D卡通恶搞、大头角色与踏板变形，验证第一幕真诚好笑。
- [ ] 清算/洪流视觉转折打磨。
- [ ] 金属事件音不重复滥用；落实0.5秒全静音与安静结局。
- [ ] 离线文案扩充；如作者明确要求，再生成候选并人工筛选，因果规则不由生成服务决定。
- [ ] 可选视频V1/V2/V3仅填演出插槽；未授权不得生成，素材缺失/失败必须2D fallback。

### ☐ D7：测试 + 打包

- [ ] 全流程至少5遍，覆盖提前发帖、三次未断、变形、断裂换车与不同发帖选择。
- [ ] 关闭生成服务/网络、移除视频仍可完成模板与2D流程。
- [ ] PC与移动真机输入、DPR/安全区、后台恢复、低帧率、媒体失败和跨启动档案验证。
- [ ] 修复问题、LSP检查与官方构建；发布/上传另需明确授权。
