# 《舆论刹车》 Brake the Noise

> GameJam 题目：**涌现** ｜ 七阶段开发 ｜ 单人 ｜ 2D 卡通恶搞 ｜ 荒诞恐怖
> 最近更新：2026-10-14。首版面向 PC 与移动端，单机运行；最新规则已补充文档，玩法代码尚未对齐。

## 这是什么

一款目标约 10 分钟的三幕单次闭环游戏。

> 你是一名汽车测试员。你在测试台上最多测试三次，踏板可能正常、变形或断裂。
> 然后你发了一条帖。
> 最后你看着自己那句话，长成了一个你从未说过的世界。

**核心表达**：涌现不是“我理解了这个系统”，而是“这个系统不再是我的了”。

## 一句话流程

```text
【第一幕】测试台（两轮：落点含接触 → 力度；踩空流程待定）
        ↓
   再测一轮 / 发帖？（同局最多三次；断裂可换车，次数不重置）
        ↓
【第二幕】发帖（测试历史解锁词条 → 拼句子 → 选时机）
        ↓
【第三幕】舆论洪流（因果清算 → 原帖出现 → 曲解蔓延 → 多帖聚焦）
```

## 最新载荷与状态模型

```text
T = F × L × A有效 × K姿势
A有效 = A集中(交集面积/踏板面积) × E传导(交集面积/鞋底面积)
M有效 = M剩余 × C温度(θ)
```

- **L**：杆端为支点，所有有效接触统一使用真实交集面积重心；鞋中心另存为操作落点。归一化场景几何不随窗口尺寸改变。
- **A有效**：小鞋底充分踩中可集中载荷；大鞋底仅擦到一角需传导衰减。A集中有上限，E为零到一的有界效率；具体曲线待填，不默认E等于接触率。零交集为踩空，不进入载荷计算，机会消耗和阶段出口待定。
- **F**：实际踩踏力度80～1612 N，超出截断；通常在1600 N内是调校目标，不在锁定后随机改值。疲劳减弱力量，暴躁扩大高力度位置占比。
- **甜蜜区**：最低力度/从容控制理想区，不是断裂最佳区。中心0.50，最大漂移±0.18（±18个百分点），全宽0.10～0.04，仅暴躁收窄；疲劳与暴躁共同影响漂移，每轮中心固定，向两端连续渐变。不延迟按停，也不默认最低力度就是完美停车。
- **K**：最终仅姿势。旧k1/k2/k6/k8删除；k3疲劳、k5暴躁进入F形成过程；k7温度改为一个平滑变量，分别影响人体状态累积与部件M，不重复相乘。
- **损伤**：先比较本轮T与本轮M有效，再将未断情况下的新增永久损伤记入下一轮。普通载荷损伤为零或很小，接近边界才明显增加；不固定扣寿命、不加额外断裂骰子或三次保底。温度影响可恢复，永久损伤不可逆。

T是游戏等效破坏载荷，不是严格物理扭矩或实车材料结论。正式映射、状态累积、温度和损伤参数由作者提供或明确授权调校，不能沿用旧草案或Demo值。

## 三条最该记住的约束

1. **局内不可预知，局外可追溯**（公理A1'）
   局内结算只展示本次F、感觉用时及实际用时，不展示T或隐藏状态数字；局外测试档案记录完整来源。感觉用时为真实墙钟时间，显示封顶4秒、原始值保留；实际用时来自刹车模拟，不硬编码差异倍数。
2. **喜剧必须真诚**（公理A8）
   第一幕必须真的好笑，第三幕的反思才成立，不能“装喜剧骗人”。最终帖署名玩家但不是玩家原话，安静定格，无独立系统总结或局内重开按钮。
3. **同局最多三次，换车不重置次数**
   首次测试后可提前发帖，第三次后必须发帖。断裂是耦合结果而非目标；换车不清空人体状态与历史，不以“运气”新增断裂随机。踩空机会与流程仍待定，不擅自免费重试。
