# 舆论刹车\_项目README

# 《舆论刹车》 Brake the Noise

> GameJam 题目：**涌现** ｜ 7 天 ｜ 单人 ｜ 2D 卡通恶搞 ｜ 荒诞恐怖

---

## 这是什么

一款 10 分钟的单次闭环游戏。

> 你是一名汽车测试员。你在测试台上反复踩刹车，直到踏板断裂。
> 然后你发了一条帖。
> 最后你看着自己那句话，长成了一个你从未说过的世界。

**核心表达**：涌现不是"我理解了这个系统"，而是"这个系统不再是我的了"。

## 一句话流程

```
【第一幕】测试台（2 轮判定：落点 → 力度）
        ↓
   ★ 决策点：再测一台 / 发帖？
        ↓
【第二幕】发帖（测试数据解锁词条 → 拼句子 → 选时机）
        ↓
【第三幕】舆论洪流（因果清算 → 原帖出现 → 曲解蔓延 → 结局聚焦）
```

---

## 三条最该记住的约束

1. **局内不可预知，局外可追溯**（公理 A1'）
玩的时候什么都看不到；玩完可在「测试档案」查到全部因素数据。
2. **喜剧必须真诚**（公理 A8）
第一幕必须真的好笑，第三幕的反思才成立。不能"装喜剧骗人"。
3. **测试上限 3 次，断裂是意外不是目标**
玩家会期待断，但无法控制它。"三台全断"应该是极罕见的运气。
